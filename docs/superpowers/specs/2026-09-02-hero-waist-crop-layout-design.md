# Hero 腰部特写排版调整规格

## 目标

重新整理首屏格式，将高清半身人物进一步放大并裁剪至腰部附近。通过更清晰的后层标题、人物层和前层姓名建立海报式视觉焦点，同时保留作品集网站所需的导航、身份说明和滚动引导。

## 桌面端构图

- Hero 保持全屏高度，内容版心仍以约 1200px 为基准。
- 人物视觉放大约 `25%–35%`，显示头部、肩部、上身和腰部附近。
- 人物中心位于首屏宽度约 `58%`，脸部位于视口上半区的视觉中心。
- 人物头发与导航之间保留至少约 60px 安全距离。
- 人物腰部允许在视口下方自然裁切，不压缩人物比例。

## 标题层级

- 后层标题为 `HI, I'M`，放置在人物肩部后方。
- 后层标题字号增大、对比度降低，不能覆盖面部关键区域。
- 前层标题为 `TINGTING.`，横跨人物腰线附近，并位于人物前方。
- 前层标题保持暖银渐变，句点使用香槟金。
- 两层标题共同覆盖较宽区域，但不得超出页面产生横向滚动。

## 辅助信息

- `VISUAL DESIGNER · SHENZHEN` 眉题保留在左上内容区。
- 中文身份说明移动至左下，并缩窄文本宽度。
- 右侧人物标签移动至肩部外侧，避免与姓名标题冲突。
- 页面底部滚动引导保留并保持居中。

## 背景与动效

- 透视方格主要集中在首屏下半部分，减少人物面部区域的线条干扰。
- 深酒红与铜金极光集中在人物背后，强化轮廓但不形成明显光圈边界。
- 折面和颗粒继续使用，但整体透明度略微降低。
- 鼠标移动时人物最大平移约 `7px`，倾斜不超过 `1.5deg`。
- 后层标题轻微反向移动，前层标题轻微正向移动。
- 鼠标离开后所有元素平滑归位。

## 移动端

- 920px 以下人物居中偏右，保持头部完整。
- 620px 以下人物显示至胸腰之间，避免人物过小。
- 后层标题位于人物头肩后方，前层姓名位于人物下胸或腰线前方。
- 中文说明位于底部安全区，不与滚动提示重叠。
- 人物标签在空间不足时隐藏。
- 触屏端关闭鼠标跟随，仅保留轻微慢速漂浮。

## 实现范围

- 复用当前透明背景高清人物素材，不重新设计人物。
- 主要通过 Hero 布局、图片尺寸、定位和标题样式完成调整。
- 不修改导航、后续章节、联系方式或全站配色。
- 不增加新的图片依赖或外部组件。

## 验收标准

- 桌面端人物清晰显示并自然裁剪至腰部附近。
- 人物面部是第一视觉焦点，未被文字、方格或标签遮挡。
- `HI, I'M` 明确位于人物后方，`TINGTING.` 明确位于人物前方。
- 中文说明、人物标签和滚动提示互不重叠。
- 1440px、920px 和 390px 宽度下无横向溢出。
- 减少动态效果模式下所有层保持稳定。
- 本地预览可用，生产构建成功。

## 本次不包含

- 重新生成人物或修改透明背景素材。
- 调整 Hero 之外的章节。
- 新增真实作品图片和项目详情页。
