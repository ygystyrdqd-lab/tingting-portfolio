# 首屏双行标题间距优化设计

## 目标

将首屏 `HI, I'M` 与 `TINGTING.` 两行标题之间的垂直空隙缩短约一半，并重新平衡标题组在人物胸腰区域的整体位置。保留当前人物前后穿插关系和高端视觉层次。

## 定位调整

- 常规 PC：上行 `top` 从 `29%` 调整为 `34%`；下行 `bottom` 从 `15.5%` 调整为 `22%`。
- 高度不超过 `760px` 的 PC：上行 `top` 调整为 `35%`；下行 `bottom` 调整为 `20%`。
- 宽度不超过 `920px`：上行 `top` 调整为 `29%`；下行 `bottom` 调整为 `23%`。
- 宽度不超过 `620px`：上行 `top` 调整为 `24%`；下行 `bottom` 调整为 `27%`。

## 范围

- 仅修改 `src/App.css` 中现有 Hero 标题定位规则。
- 不修改字号、字距、颜色、层级、人物尺寸、人物裁剪或背景。
- 不修改 GSAP Opening 动画、鼠标视差和响应式断点。

## 验收标准

- 两行标题的视觉空隙约为修改前的一半。
- 标题组整体保持在首屏视觉中心，不挤压顶部导航和底部说明。
- PC、矮屏 PC、平板和手机均同步收紧。
- 人物仍然位于两行标题之间，前后遮挡关系不变。
- 项目可正常构建，无新增代码检查错误。
