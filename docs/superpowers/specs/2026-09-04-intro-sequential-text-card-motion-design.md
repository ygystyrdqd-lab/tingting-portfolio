# 首屏文字与卡片分段进场动效设计

## 目标

把新首屏的标题动画和扇形卡片动画拆成前后两个清晰阶段：先用快速、明确的横向揭幕建立文字冲击力，再让五张卡片从画面中心向两侧展开。整体保持当前暗色香槟金视觉体系，节奏高级、顺滑，不使用弹跳。

## 范围

- 调整新首屏标题与卡片的 opening animation 时序。
- 调整五张扇形卡片的视觉层级与中心卡片尺寸。
- 保留现有百分比加载动画、首屏文案、卡片内容、背景与页面结构。
- 不恢复已移除的手风琴展示模块。
- 不修改后续人物首屏、关于、作品、优势及二级作品页。

## 动画顺序

1. 百分比加载动画按当前逻辑完成。
2. 顶部身份标签出现。
3. 第一行 `Designing` 从左向右快速揭开并轻微横移归位。
4. 间隔约 `0.08s`，第二行 `Visual Experiences` 以相同方式揭开。
5. 中文说明文字紧随标题淡入。
6. 标题主体完成后停顿约 `0.15s`，五张卡片开始展开。
7. 卡片从共同中心向外扩散，顺序为：中心卡片 → 左右内侧卡片 → 左右外侧卡片。
8. 滚动提示在卡片展开阶段末尾出现。

标题采用遮罩揭开与短距离水平位移，不使用普通整体淡入。单行揭开约 `0.42s`；卡片展开约 `0.55s`，相邻层级错开约 `0.05s`。完整 opening animation 控制在约 `5.4–5.6s`。

## 卡片层级与尺寸

- 中心卡片保持最高层级，并向上轻提。
- 中心卡片尺寸为两侧普通卡片的 `1.25×`。
- 桌面端普通卡片宽约 `190px`，中心卡片宽约 `238px`。
- 平板端普通卡片宽约 `150px`，中心卡片宽约 `188px`。
- 手机端普通卡片宽约 `112px`，中心卡片宽约 `140px`。
- 左右卡片继续保持当前扇形角度和重叠关系，避免中心卡片放大后挤压整体画面。

## 动效技术

- 继续使用现有 GSAP opening timeline，不增加新的动画依赖。
- 标题使用 `clip-path: inset()` 配合 `x` 位移完成从左到右揭幕。
- 卡片继续从共同中心坐标出发，使用 GSAP 的 `from: center` stagger 实现中心向两侧展开。
- 使用 `power3.out` / `power4.out` 一类非弹性缓动，保持克制。
- 动画结束后清理临时 transform 与 visibility 样式，避免影响悬停和响应式布局。

## 响应式与无障碍

- PC、平板与手机遵循相同的文字先行、卡片随后逻辑。
- 手机端允许外侧卡片在画面边缘自然收束，但中心卡片必须完整清晰。
- `prefers-reduced-motion: reduce` 下跳过分段运动，直接显示最终状态。
- 不增加持续运行的粒子或高频逐帧计算，不影响当前页面性能。

## 验收标准

- 标题两行能明显看出从左到右依次揭开，而非同时淡入。
- 标题结束后卡片才开始展开，两个阶段层次清晰。
- 卡片展开顺序为中心、内侧两张、外侧两张。
- 中心卡片肉眼可见比两侧大约四分之一，且不被裁切。
- 动画无弹跳、无突兀闪烁，结束后卡片悬停效果仍正常。
- 桌面端和手机端无新增横向滚动条。
- 项目构建与现有检查通过。
