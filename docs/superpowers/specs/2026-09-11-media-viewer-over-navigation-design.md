# 作品查看器覆盖导航栏设计

## 目标

“项目”屏的卡片打开全屏作品查看器后，网站全局导航栏不再显示在图片上方。查看状态只保留作品标题、编号、媒体内容和关闭按钮。

## 实现方式

- `MediaViewer` 使用 React `createPortal` 渲染到 `document.body`。
- 保留现有 `.media-viewer` 全屏固定定位和 `z-index: 1000`。
- Portal 使查看器脱离首页 `<main>` 的层叠上下文，因此能稳定覆盖 `z-index: 100` 的全局导航。
- 不通过隐藏样式或额外 App 状态控制导航，避免关闭后遗留不可见导航。

## 保持不变

- 查看器的布局、颜色、标题栏、图片比例和视频控件不变。
- 保留关闭按钮、遮罩点击关闭、`Esc` 关闭和背景滚动锁定。
- “项目”屏三张卡片仍直接打开作品媒体，URL 保持 `#projects`。
- “作品”分类二级页面内的查看器也使用同一 Portal，但其当前显示效果不变。

## 验收标准

1. 从“项目”屏打开任一作品时，页面不再显示 `LT`、首页、关于、作品、项目和联系我等全局导航内容。
2. 查看器顶部保留作品名称、编号和右上角关闭按钮，且按钮可操作。
3. 关闭查看器后，全局导航栏正常恢复，项目屏滚动位置不变。
4. 项目查看、二级页查看、构建和桌面体验检查全部通过。
