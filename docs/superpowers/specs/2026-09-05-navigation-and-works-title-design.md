# 导航与第三屏作品标题调整设计

## 目标

统一首页导航与第三屏内容语义，将导航中的“优势”改为“项目”，并将第三屏英文主标题改为“SELECTED WORKS”。

## 修改范围

- 顶部导航最终显示为“首页 / 关于 / 作品 / 项目”。
- 原“优势”导航项仅修改显示文字为“项目”，锚点保持 `#projects` 不变。
- 原“作品”导航项继续指向 `#capabilities`。
- 第三屏主标题由两行“CAPA / BILITIES”改为两行“SELECTED / WORKS”。
- 保留第三屏 `id="capabilities"`、动画数据属性、分类列表、浅色背景和二级页面链接。
- 不修改第四屏 `PROJECTS.` 标题及其内容。

## 验收标准

- 导航显示“首页 / 关于 / 作品 / 项目”。
- 点击“项目”仍滚动到 `#projects`，点击“作品”仍滚动到 `#capabilities`。
- 第三屏主标题准确显示两行“SELECTED / WORKS”，原有 GSAP 进场动画仍运行。
- PC 与 390px 手机端标题无裁切、页面无横向溢出。
- lint 与生产构建通过，仅记录项目已有且与本次修改无关的警告。
