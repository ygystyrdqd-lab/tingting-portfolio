# 视觉设计师作品集参考版式重搭规格

## 目标

按照用户提供的 3D Creator 参考网站重新搭建廖婷婷的个人作品集。复用其超大排版、滚动叙事、明暗章节切换与项目卡片层叠方式，但不复制参考中的 Jack 身份、文案、第三方作品图片、项目名称或装饰素材。

本次重搭仍处于内容框架阶段：不导入廖婷婷的正式作品图片。涉及图像的位置使用 React Bits Pro Hero 7 自带的展示能力或抽象占位视觉，后续再替换为真实作品。

## 技术方向

- 保持 React + Vite 项目。
- 将现有 JSX 入口与组件迁移为 TypeScript/TSX，以兼容参考结构与 React Bits Pro block。
- 初始化 shadcn/ui，并配置 `components.json` 的 React Bits Pro registry。
- registry 请求通过 `REACTBITS_LICENSE_KEY` 环境变量授权；密钥只保存在 `.env.local`，不得写入源码、日志或提交文件。
- 安装 `@reactbits-pro/hero-7`，优先复用 block 的组件结构与依赖。
- 使用 Tailwind CSS 负责页面布局和常规样式，复杂动画保留组件级 CSS 或 Framer Motion。
- 使用 Framer Motion 实现入场、逐字显现和项目层叠滚动。
- 使用 Lucide React 提供必要的界面图标；不增加无关图标装饰。

## 页面结构

### 1. HeroSection

- 全屏高度、深黑背景、横向溢出裁切。
- 顶部导航采用参考网站的四点均分结构：关于、能力、项目、联系。
- 主标题改为 `HI, I'M TINGTING`，使用银灰纵向渐变、大写、超宽排版。
- Hero 7 的 3D 旋转视觉位于屏幕中央，替代参考中的人物图。
- 背景增加高速横向移动的透视方格；方格仅作背景，不影响标题可读性。
- Hero 7 保留粉色发光条与粒子，荧光黄绿色仍作为网站主识别色，用于状态、细节和联系区。
- 左下角展示视觉设计师身份说明，右下角为联系按钮。
- 移动端降低方格速度、粒子数量与 3D 细节，避免遮挡文字并控制性能。

### 2. MarqueeSection

- 双排横向视觉带，第一排随滚动向右，第二排向左。
- 当前不加载正式作品图；使用带编号、类别与抽象纹理的占位卡片。
- 每排内容重复三次实现无缝视觉循环，滚动计算使用被动监听或 Framer Motion scroll value。
- `prefers-reduced-motion` 下停止持续位移，只保留静态横向卡片带。

### 3. AboutSection

- 深黑全屏章节，居中显示超大 `ABOUT ME` 银灰渐变标题。
- 使用简历内容改写介绍：平面设计本科、10 年一线商业设计经验、品牌视觉与 AIGC 融合能力。
- 介绍文字随滚动逐字从低透明度过渡到高透明度。
- 参考中的四个外部 3D 装饰图不使用，改为轻量抽象轨道、网格切片和编号标记，避免复制原站素材。
- 保留联系按钮，引导至页面尾部。

### 4. ServicesSection

- 白色背景、超大圆角顶部，与深色章节形成强烈切换。
- 标题为 `CAPABILITIES`。
- 五项能力采用巨型编号与横向说明列表：品牌视觉、电商视觉、包装设计、三维视觉、AIGC 创意工作流。
- 文案基于简历能力范围，不虚构公司经历或项目数据。

### 5. ProjectsSection

- 深黑背景、超大圆角顶部，并向上覆盖白色能力章节。
- 标题为 `SELECTED PROJECTS`。
- 三张项目卡采用 sticky 层叠滚动和轻度缩放。
- 卡片内部延续参考的 40/60 图像布局，但当前使用抽象占位区域，不接入第三方图片。
- 项目名称使用通用类别占位：品牌视觉项目、电商视觉项目、包装设计项目。
- “查看项目”按钮暂时禁用并显示“内容整理中”，避免无效链接。

### 6. ContactSection

- 追加荧光黄绿整屏联系区，延续当前站点已有的个人识别。
- 主标题为 `HAVE A PROJECT? LET'S TALK.`。
- 展示邮箱 `806779987@qq.com`、深圳所在地和返回顶部链接，不公开手机号。

## 组件边界

- `PortfolioPage`：只负责章节编排。
- `HeroSection`：标题、导航、Hero 7 与快速方格背景。
- `FastGridBackground`：独立控制方格运动、鼠标偏移和减少动态效果。
- `Hero7`：registry 安装的 3D 旋转视觉，外层只通过 props 和设计 token 适配。
- `MarqueeSection`：双排占位视觉带及滚动位移。
- `AboutSection`、`AnimatedText`：个人介绍和逐字显现。
- `CapabilitiesSection`：能力数据列表。
- `ProjectsSection`、`ProjectCard`：sticky 项目层叠。
- `ContactButton`、`ContactSection`：统一联系动作与结尾。
- 页面文案和占位项目数据集中存放，避免硬编码散落在组件内。

## 交互与数据流

- 页面无接口请求、表单或持久化数据。
- 视口滚动值驱动跑马灯、逐字显现与项目卡缩放。
- 鼠标位置只在 Hero 可见时驱动方格与 3D 视觉的轻微偏移。
- 导航使用锚点跳转；联系按钮使用 `mailto:`。
- 所有动画组件在卸载时移除监听，持续动画使用 transform 与 opacity，避免布局抖动。

## 回退与错误处理

- React Bits registry 安装失败时停止实施并报告授权或网络错误，不伪造 Pro block 源码。
- Hero 7 运行失败时保留标题、导航和快速方格背景，首屏仍可使用。
- WebGL 或高性能动画不可用时降级为静态卡片堆叠。
- 未提供项目图时始终显示设计好的占位视觉，不出现破图。

## 响应式与可访问性

- 以 1440px PC 展示为主，兼容 768px 和 390px 宽度。
- 流体字号使用 `clamp()`；卡片与标题不得造成横向页面滚动。
- 保留键盘焦点、语义化章节、可访问导航与足够对比度。
- 尊重 `prefers-reduced-motion`，关闭持续方格、粒子、磁吸和大幅滚动动画。

## 验收标准

- shadcn 与 React Bits Pro registry 配置完成，密钥未进入可提交文件。
- `@reactbits-pro/hero-7` 由官方 registry 安装并成功渲染。
- 页面顺序为 Hero、双排视觉带、关于、能力、项目、联系。
- Hero 显示高速移动方格、3D 旋转视觉、粉色发光条和粒子。
- 参考网站的第三方图片、名称和原文案没有进入项目。
- 当前版本不导入廖婷婷的正式作品图片。
- 桌面与基础移动布局无明显溢出；减少动态效果模式可用。
- 本地预览无阻塞运行错误，生产构建成功。

## 本次不包含

- 正式作品素材导入与项目详情页。
- 后台、CMS、联系表单或数据存储。
- 参考网站外部图片的下载、复用或热链接。
- 部署发布；本阶段继续使用本地预览。
