# 首屏中心卡片文字避让设计

## 目标

解决首屏中心卡片与上方说明文字距离过近、产生视觉遮挡的问题，同时保留中心卡片作为扇形卡片组视觉焦点的层级。

## 调整范围

- 仅调整首屏中心卡片 `.intro-fan__slot--3` 的宽度与垂直位置。
- 不调整左右四张卡片、标题、说明文字、卡片展开顺序或 opening animation 时长。
- 不调整人物页、关于、作品、优势及二级页面。

## 响应式尺寸

- PC：中心卡片宽度从 `238px` 改为 `228px`，即普通卡片 `190px` 的 `1.2×`；水平偏移改为 `-114px`，垂直位置从 `-22px` 改为 `-8px`，视觉下移 `14px`。
- 平板：中心卡片宽度从 `188px` 改为 `180px`，即普通卡片 `150px` 的 `1.2×`；水平偏移改为 `-90px`，垂直位置从 `-16px` 改为 `-6px`，视觉下移 `10px`。
- 手机：中心卡片宽度从 `140px` 改为 `134px`，约为普通卡片 `112px` 的 `1.2×`；水平偏移改为 `-67px`，垂直位置从 `-12px` 改为 `-4px`，视觉下移 `8px`。

中心卡片始终以自身宽度的一半进行水平居中，保持扇形构图对称。

## 动效兼容

GSAP 在动画开始时通过卡片最终布局重新计算中心偏移，因此 CSS 尺寸改变后无需修改时间线。动画完成时仍清理临时 transform，保留现有卡片悬停效果。

## 验收标准

- 中心卡片与中文说明文字之间存在清晰留白，不再产生遮挡感。
- 中心卡片仍明显大于左右卡片，但视觉压迫感降低。
- 五张卡片构图保持水平对称，中心卡片没有偏移。
- PC、平板和手机端均无新增裁切或首屏横向溢出。
- 标题揭幕与卡片展开顺序保持不变。
- Vite 生产构建通过，且不产生新的 lint 问题。
