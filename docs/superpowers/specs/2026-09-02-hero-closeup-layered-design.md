# Hero 高清半身特写与分层排版规格

## 目标

参考用户提供页面的核心构图逻辑，将当前 Hero 从右侧全身人物改为中心偏右的高清半身大特写，并通过人物、标题和背景的前后分层提升视觉冲击力。继续使用石墨香槟金体系，不复制参考页面的人物、文字、紫色品牌色或装饰素材。

## 人物素材

- 使用用户提供的个人 3D 形象作为唯一人物来源。
- 生成高清半身版本，构图从头部覆盖至大腿附近。
- 保持人物面部、发型、铜金服装、身体比例和姿态特征一致。
- 强化头发、面部、服装高光和透明材质的细节清晰度。
- 使用纯黑合成底配合网页混合模式，避免再次产生棋盘格或白色底纹。
- 输出文件存入项目 `public` 目录，原始素材保持不变。

## 首屏构图

- Hero 保持全屏高度，导航位置不变。
- 人物位于画面中央偏右，头部距离导航保留安全空间。
- `HI, I'M` 作为后层标题，位于人物肩部后方。
- `TINGTING` 作为前层标题，横跨人物腰部以下区域。
- 前后两层标题使用暖银渐变，香槟金仅用于少量标点和身份信息。
- 左下保留中文身份介绍，右侧增加简短人物身份标签。
- 透视方格降低存在感，不穿过人物面部。

## 背景质感

- Hero 基础背景由纯石墨黑改为深酒红、暖石墨和铜棕组成的多层径向渐变。
- 增加两组大尺寸低透明极光，运动速度慢于现有粒子。
- 增加低透明抽象折面，采用 CSS 渐变和裁切几何实现，不使用参考图素材。
- 增加轻微噪点层，控制在不影响文字锐度的强度。
- 页面下方已有慢速极光体系保持不变，Hero 使用更精细的局部背景层。

## 2.5D 交互

- 鼠标在 Hero 人物区域移动时，人物最大平移约 `10px`、倾斜不超过 `2deg`。
- 后层标题与背景折面以较小反向幅度移动。
- 前层 `TINGTING` 以更小的正向幅度移动，建立三层景深。
- 人物悬停时清晰度、轮廓光和局部对比度轻微增强。
- 鼠标离开后所有层平滑回到初始位置。
- 不使用翻转、快速缩放、强烈抖动或持续追踪光点。

## 响应式与降级

- 桌面端以约 1440px 宽度为主要构图基准。
- 920px 以下人物居中，标题前后层仍保留但缩小间距。
- 620px 以下人物显示头部至膝部附近，避免过度裁切面部与服装主体。
- 触屏设备关闭指针跟随，仅保留慢速轻微漂浮。
- `prefers-reduced-motion: reduce` 下关闭人物、标题、折面和粒子位移。
- 人物图片加载失败时显示暖色渐变人物占位。

## 组件调整

- `Hero` 改为明确的后层标题、人物层和前层标题结构。
- `HeroAvatar` 继续负责人物加载与指针坐标计算，但改用半身构图参数。
- 背景新增独立的局部光层、折面层和噪点层，全部设置 `aria-hidden="true"`。
- 指针坐标通过 CSS 自定义属性传递给人物、文字和背景装饰，避免频繁 React 重渲染。

## 验收标准

- Hero 显示清晰的个人半身 3D 形象，不出现白色、棋盘格或明显黑色矩形底纹。
- 人物细节在桌面屏幕上明显优于当前全身版本。
- `HI, I'M` 位于人物后方，`TINGTING` 位于人物前方，层级清晰。
- 背景不再是视觉上的纯黑平面，能看到深酒红、铜棕极光、折面和细颗粒。
- 鼠标滑过具有三层轻微景深，不影响阅读。
- 移动端无明显重叠或横向溢出。
- 减少动态效果模式可用。
- 本地预览可用，生产构建成功。

## 本次不包含

- 复制参考页面的紫色配色、姓名、按钮或人物素材。
- 制作真正的三维模型和骨骼动画。
- 修改 Hero 之外的章节结构和内容。
