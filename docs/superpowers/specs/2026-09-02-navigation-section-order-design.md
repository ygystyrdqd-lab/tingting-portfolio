# 导航与模块顺序调整规格

## 目标

按指定映射修正顶部导航链接，并恢复页面模块的原始滚动顺序。同时保持个人优势列表中 AIGC 条目已删除的状态。

## 导航

顶部导航固定为以下顺序：

1. `首页` → `#home`
2. `关于` → `#about`
3. `作品` → `#capabilities`
4. `优势` → `#projects`

不修改品牌标识、联系按钮、移动端菜单行为或锚点 ID。

## 页面模块顺序

主内容区调整为：

1. Hero 首页
2. 视觉方向滚动展示
3. 个人介绍
4. Capabilities 模块
5. Projects 模块
6. 联系方式页

恢复 `Capabilities` 在前、`Projects` 在后的渲染顺序，不移动或复制模块内部内容。

## 优势列表

- 删除 `05 AIGC 创意工作流 / AI Workflow`。
- 保留 `01 品牌视觉设计`、`02 电商与活动视觉`、`03 包装与物料延展`、`04 三维视觉表现`。
- 删除后列表连续结束于 `04`，不保留空白行或占位内容。

## 实现范围

- 修改 `src/App.jsx` 中的 `navItems`、`capabilities` 数据和 `App` 渲染顺序。
- 不修改 CSS、Hero、人物图片、项目卡片内容、联系方式或其他交互。

## 验收标准

- 桌面与移动端导航均显示 `首页 / 关于 / 作品 / 优势`。
- 点击“作品”定位到 `#capabilities`，点击“优势”定位到 `#projects`。
- 页面滚动时 `Capabilities` 位于 `Projects` 之前。
- 优势列表仅显示 `01–04`，不再出现 AIGC 创意工作流。
- 生产构建成功，本地预览可访问。
