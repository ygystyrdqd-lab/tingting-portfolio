# 二级作品页回顶与悬浮导航设计

## 目标

四个作品分类二级页面每次打开时始终从页面顶部开始展示，并让二级页胶囊导航在滚动过程中持续悬浮可见。

## 适用入口

回顶行为必须覆盖以下入口：

- 从首页作品分类区域点击进入二级页面。
- 直接打开带有 `?category=` 参数的二级页面链接。
- 使用浏览器前进或后退进入、切换二级页面。

从二级页面点击“返回作品”时，继续返回首页的作品分类区域，不改为首页顶部。

## 回顶行为

- 在 `WorkCategoryPage` 内使用 `useLayoutEffect`，并以 `category.slug` 为依赖。
- 组件首次挂载或分类 slug 改变时先同步回顶，再于下一动画帧重复回顶，以覆盖首页 GSAP 清理阶段恢复旧滚动位置的情况。
- 回顶不使用平滑滚动，避免用户先看到旧滚动位置再跳到顶部。
- 无效分类页面也从顶部打开。
- 保留 `App.jsx` 中现有点击进入时的回顶调用作为即时保护；组件级回顶负责覆盖直接链接和浏览器历史切换。

## 悬浮导航

- `.work-detail-nav` 从普通流内的 `position: relative` 改为 `position: sticky`。
- `.work-detail` 的横向裁切从 `overflow: hidden` 改为 `overflow: clip`，避免父级成为 sticky 的非滚动容器。
- PC 与平板端保持 `top: 18px`，移动端使用 `top: 10px`。
- 导航继续占据原有文档流高度，不需要给下方标题增加人工占位。
- 保留当前 `1200px` 最大宽度、胶囊圆角、半透明暗色背景和模糊效果。
- 提高导航层级，使其滚动经过标题和项目卡片时始终位于内容上方。
- 不改动品牌入口、“返回作品”和“联系我”的内容与行为。

## 文件职责

- `src/components/work/WorkCategoryPage.jsx`：在二级页面挂载或分类改变时执行可靠回顶。
- `src/components/work/work-detail.css`：定义导航的 sticky 悬浮位置与响应式顶部间距。
- `src/App.jsx`：保持现有分类状态与返回作品逻辑，不进行结构性修改。

## 动画兼容

- 回顶在 `useWorkDetailAnimations` 创建 GSAP 进场动画之前的同一布局阶段完成。
- 现有标题自上而下进场、卡片 ScrollTrigger 和图片视差逻辑保持不变。
- sticky 导航不参与 GSAP transform，避免与浏览器的吸顶定位冲突。
- `prefers-reduced-motion` 只影响动效，不影响回顶和悬浮导航。

## 验收标准

- 从首页任意分类进入时，二级页 `scrollY` 为 `0`。
- 直接访问四个 `?category=` 链接时均从顶部展示。
- 浏览器前进和后退切换分类时均从顶部展示。
- 向下滚动至项目卡片和页面底部时，导航仍悬浮可见。
- PC/平板导航距离视口顶部 `18px`，手机端距离顶部 `10px`。
- 返回作品后仍定位首页作品分类区域。
- 四个二级页的现有进场动效、项目卡片点击和媒体查看器保持正常。
- Vite 生产构建通过，且不产生新的 lint 问题。
