# 第二屏个人形象与指尖水波纹设计规格

## 目标

将首页第二屏“关于”模块的个人形象替换为 `个人ID/1.png`，并围绕画面中向镜头伸出的前景手指建立一个明确、克制且低性能开销的指针互动。互动应强化人物主动与访客建立连接的感觉，同时延续网站现有的暗色、香槟金视觉语言。

## 视觉构图

- 使用透明背景的 `个人ID/1.png`，复制到站点公共资源目录，避免依赖工作区外部路径。
- 对人物图执行高保真透明边缘修复：去除头发、手臂、手指和裙摆轮廓上的白色/灰色底色污染，同时保留发丝、半透明布料和细小轮廓。
- 将最终网页资源提升为约 2K 纵向分辨率；增强真实细节和边缘清晰度，但不得重绘或改变人物身份、五官、发型、动作、手势、服装结构、颜色、身体比例及构图。
- 输出必须保留真实 Alpha 透明通道，不加入背景、投影、描边、文字或水印；站点中的背景和阴影继续由 CSS 提供。
- 人物在第二屏图片卡中完整呈现主体轮廓，重点保留面部、红色服装和前景手指，不裁掉前景指尖。
- 卡片沿用现有暗色渐变、细网格和香槟金光晕；红色服装作为局部高饱和视觉焦点，不额外加入新的主题色。
- 指尖触发点以图片原始构图为基准定位，并随卡片尺寸按比例缩放。

## 指尖互动

- 仅在桌面端、精确指针设备上启用完整互动。
- 鼠标进入人物卡后，计算指针与前景指尖热点的距离。
- 当鼠标进入指尖附近的感应范围时，出现轻微磁吸反馈：指针光点向指尖收拢，人物只产生非常小的景深位移。
- 当鼠标与指尖热点接触时，从指尖中心依次扩散 3 层水波纹；波纹采用香槟金细线和柔和辉光，不使用弹跳或高频闪烁。
- 水波纹每次接触只触发一次；离开热点后重置，重新接触才再次触发，防止持续动画造成干扰。
- 建议节奏：单层波纹约 700–900ms，相邻波纹错开约 100–140ms，使用自然减速曲线。

## 实现方案

- 在 `About` 组件中增加专用的互动人物卡组件或局部状态逻辑。
- 使用 Pointer Events 读取卡片内相对坐标，通过 CSS 自定义属性传递指针位置和感应强度。
- 波纹使用绝对定位的 HTML 元素配合 CSS `transform` 与 `opacity` 动画实现，不引入 Canvas、WebGL 或新依赖。
- 热点元素不拦截点击，卡片保持现有语义；装饰元素设置 `aria-hidden="true"`。
- 图片加载失败时保留现有卡片背景与标签，不影响关于模块文字内容。

## 性能与无障碍

- 动画仅修改 `transform` 和 `opacity`，避免触发布局计算。
- 离开卡片或页面不可见时不运行循环动画；本方案默认无持续循环。
- `prefers-reduced-motion: reduce` 下取消磁吸和扩散位移，仅保留一次短暂的静态光晕反馈。
- 粗指针和触屏设备不启用跟随效果，避免虚假的悬停状态。

## 验收标准

- 第二屏显示 `个人ID/1.png`，透明边缘干净，人物主体和前景指尖均未被意外裁切。
- 深色网页背景下，人物头发、手臂、手指和裙摆周围不出现连续白边或灰色光圈；放大查看时细小发丝与半透明衣料仍然自然。
- 最终人物资源的纵向分辨率不低于 2000px，且五官、动作、服装与原始图片保持一致。
- PC 端鼠标靠近并接触指尖时，波纹从视觉上的指尖位置准确产生。
- 快速移入移出、重复触发时不会累积残留波纹或产生跳动。
- 互动不改变页面布局，不影响现有滚动揭示和轻微视差。
- 构建、代码检查和桌面端浏览器预览均通过。
- 不执行 GitHub 发布或线上部署。
