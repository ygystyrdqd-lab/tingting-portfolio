# 电商与活动视觉项目图片接入设计

## 目标

将“电商与活动视觉”素材目录中的三张项目封面与三张详情长图接入对应的三个项目卡片，同时更新项目标题，并优化图片体积与详情阅读体验。

## 图片处理

- 六张图片统一输出为 WebP。
- 保持每张素材的原始像素尺寸和长宽比例，不重新裁切或放大。
- 使用质量参数 `90` 和 WebP 压缩方法 `6`，优先保护详情页小字号文字的清晰度。
- 每个项目输出 `cover.webp` 与 `detail-01.webp`。
- 用户提供的原始 JPG 和 PNG 文件保持不变。
- 使用可重复执行的 Pillow 脚本生成静态资源，并在处理前校验源图尺寸，避免错误素材被覆盖到项目中。

## 项目数据

三个项目保留现有 ID，更新标题并新增：

- `cover`：指向对应 `/work/ecommerce-0N/cover.webp`。
- `media`：包含一条 `type: 'image'` 的详情媒体，指向对应 `detail-01.webp`。
- 每条详情媒体提供与项目名称一致的中文替代文本。
- 元数据继续使用 `CAMPAIGN · E-COMMERCE`。

## 卡片与详情展示

- 复用 `WorkCategoryPage` 已有的真实封面条件渲染逻辑。
- 封面使用 `object-fit: cover` 居中填满卡片，保留卡片悬停放大、扫光、边框和标题效果。
- 三个项目自动使用现有 `layout-featured`：第一张为大通栏卡片，第二、三张在 PC 端并列。
- 宽度小于 `760px` 时三张卡片自动改为单列。
- 点击卡片后复用 `MediaViewer`，详情长图按容器宽度等比展示、不裁切，并在查看器内部纵向滚动。

## 性能与错误处理

- 卡片封面继续使用现有浏览器解码策略。
- WebP 压缩减少首次进入分类页和打开详情图时的传输体积。
- 图片加载失败时显示媒体替代文本，不增加新的复杂错误界面。
- 空媒体占位在这三个项目中不再出现；其他尚未上传媒体的分类继续保持现有空状态。

## 不变范围

- 电商与活动视觉分类的页面标题、说明、主题色与三个项目数量不变。
- 品牌视觉、包装与物料延展、三维视觉表现、AIGC 视频广告分类不变。
- 不修改项目路由、导航、返回行为与入场动画。

## 验收标准

1. 三张项目卡片分别显示正确封面和更新后的标题。
2. 第一张通栏、第二与第三张并列的 PC 布局保持正常。
3. 三张卡片分别打开正确的详情长图，长图完整且可纵向滚动。
4. 手机端三张卡片单列显示，封面无变形，详情没有横向溢出。
5. 六个 WebP 均保持预期尺寸并成功加载。
6. 原始素材文件保持不变。
7. lint 与生产构建通过，浏览器控制台无图片 404、解码或 React 渲染错误。
