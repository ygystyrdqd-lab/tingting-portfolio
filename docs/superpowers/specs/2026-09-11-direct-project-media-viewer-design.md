# 项目屏直接浏览作品设计

## 目标

将首页“项目”屏的三张项目卡片从“进入分类二级页”改为“直接浏览该项目的图片或视频”。

## 范围

- `IP视觉设计` 卡片直接打开“花小灵IP形象设计”媒体。
- `电商与活动视觉` 卡片直接打开“AOC投影仪电商视觉”的三张图片。
- `AIGC工作流` 卡片直接打开“AI空间场景生成工作流”媒体。
- 上方“作品”屏的分类入口、二级页面和返回逻辑不变。

## 交互

- 点击“项目”卡片时不改变 URL，在当前页面上打开现有 `MediaViewer`。
- 查看器标题使用卡片内部项目的真实名称，并使用项目屏卡片编号 `01–03`。
- 媒体按数据中的顺序纵向展示，图片保持原比例，视频保留播放控件。
- 支持右上角关闭按钮、点击遮罩关闭和 `Esc` 键关闭；打开时锁定背景滚动，关闭后恢复原位置。

## 实现边界

- `Projects` 管理当前选中的项目，并把 `featuredWorkCategories` 中每个分类的第一个项目传给 `MediaViewer`。
- 卡片从链接语义改为按钮语义，保留现有聚焦、悬停、Spotlight 和进场动画。
- 不删除分类数据与原二级页组件，避免影响“作品”屏和已有地址。

## 验收标准

1. 三张项目卡片点击后 URL 仍为首页 `#projects`，不再出现 `?category=`。
2. 每张卡片打开的标题和媒体与自身项目一致。
3. AOC 项目完整显示三张图片。
4. 查看器的关闭方式、滚动锁定和无障碍对话框语义保持正常。
5. 作品屏的二级页入口不受影响，项目构建通过。
