# 瑞美亚面霜广告项目卡片设计

## 目标

把首页“项目”屏原「AIGC工作流」卡片替换为「瑞美亚面霜广告」作品。沿用现有卡片和全屏媒体查看器，不新增二级页面，也不改变其他项目。

## 素材与呈现

- 封面来自 `C:/Users/Mayn/Desktop/作品集/项目/瑞美亚面霜广告封面.jpg`。此文件在首次接入后已更新（当前约 774 KB）；重新复制最新版到项目卡片，查看器也使用同一新版封面作为视频 poster。保持现有比例、圆角、Spotlight 效果和文字可读性。
- 广告原片来自 `C:/Users/Mayn/Desktop/作品集/项目/瑞美亚面霜广告.mp4`（约 66 MB、29.9 秒、1922×1080）。点击卡片后，现有全屏查看器播放压缩版，不在项目屏预加载视频。
- 卡片标题和查看器标题统一为「瑞美亚面霜广告」；项目元信息调整为 AIGC 美妆广告语义。原「AI空间场景生成工作流」内容不在本卡片中展示。
- 视频采用画质优先的 H.264 MP4 编码；若原片有音轨，转为 AAC 并保留声音。保持原片 1922×1080 的完整画面与约 29.9 秒时长，目标体积约 15–25 MB；目标是画质与加载速度的折中，不以牺牲明显的产品文字和质感为代价。若一次压缩超出范围或出现明显失真，调整编码参数并复核。
- 保留 `项目` 文件夹内原片不动；先输出临时压缩文件并核对时长、分辨率、浏览器解码和主要画面，再替换网站静态视频。当前环境没有检测到 FFmpeg，可使用获准安装/下载的临时编码工具，不把工具本身提交到站点仓库。

## 实现边界

- 只修改 `featuredWorkCategories` 中原 `aigc-workflow` 条目及其对应的本地静态素材。
- 保持项目排序、卡片数量、全屏查看器关闭方式与其他页面不变。
- 本次仅更新本地版本，不部署 GitHub Pages。后续发布前确认视频托管及 Git 历史中旧的 66 MB 视频对象；当前网站仅引用压缩版。

## 验收

- “项目”屏卡片显示新封面和新标题，无缺图或裁切异常。
- 点击卡片打开无导航栏的全屏查看器，新封面作为 poster，压缩视频可播放、可关闭，时长和 1080p 分辨率与原片一致。
- 对比原片的产品罐、品牌文字和金色光效，不能出现明显模糊或严重块状失真；记录压缩前后体积。
- 构建、现有桌面验证脚本通过，其他项目卡片不受影响。
