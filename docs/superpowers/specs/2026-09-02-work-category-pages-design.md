# 作品分类二级页面设计规格

## 目标

将第三屏 01–04 升级为四个作品分类入口。入口具有跟随鼠标位置变化的高亮效果，点击后在当前标签页进入对应的完整二级页面。二级页面先提供三张项目准备卡和媒体查看器框架，后续可直接补充真实图片或视频。

## 分类结构

四个分类使用以下固定标识：

| 编号 | 标题 | 英文 | 参数值 |
| --- | --- | --- | --- |
| 01 | 品牌视觉设计 | Brand Visual | `brand` |
| 02 | 电商与活动视觉 | E-commerce | `ecommerce` |
| 03 | 包装与物料延展 | Packaging | `packaging` |
| 04 | 三维视觉表现 | 3D Visual | `3d` |

## 首页入口交互

- 01–04 每一行整体为可点击链接，而不是只有右侧箭头可点击。
- 鼠标在行内移动时，行背景以鼠标坐标为中心显示柔和的香槟金与铜色径向光晕。
- 标题、编号、英文和箭头在悬停时同步改变颜色；箭头轻微旋转并向右上移动。
- 鼠标离开后光晕平滑淡出，元素恢复初始状态。
- 键盘聚焦时显示固定居中的高亮效果，按 Enter 可进入页面。
- 触屏端不计算指针坐标，使用按压高亮。
- 减少动态效果模式下禁用光晕位移和箭头运动。

## 路由与浏览器行为

- 不新增路由依赖。
- 二级页面使用根页面查询参数：`?category=brand`、`?category=ecommerce`、`?category=packaging`、`?category=3d`。
- 点击分类时通过 History API 更新地址并切换页面，不触发完整刷新。
- 浏览器前进和后退通过 `popstate` 与页面状态同步。
- 无参数时显示现有单页作品集。
- 参数无效时显示可恢复的“分类不存在”状态，并提供返回作品分类按钮。
- 二级页面返回按钮清除查询参数并回到 `#capabilities`。
- 顶部导航链接使用根路径加锚点，确保从二级页面也能返回首页相应章节。

## 二级页面布局

- 使用与全站一致的深石墨、酒红与香槟金视觉系统。
- 顶部包含品牌标识、返回作品分类按钮和联系按钮。
- 首屏显示分类编号、中文标题、英文标题和简短说明。
- 下方以三列大卡片展示三个“内容准备中”项目；平板两列，手机单列。
- 每张卡片包含项目序号、项目名称、媒介标签和抽象渐变预览，不使用外部图片。
- 二级页底部提供返回作品分类和联系邮箱。

## 项目数据模型

分类数据使用对象结构，后续真实内容按以下接口加入：

```js
{
  slug: 'brand',
  number: '01',
  title: '品牌视觉设计',
  en: 'Brand Visual',
  description: '...',
  projects: [
    {
      id: 'brand-01',
      title: '项目内容准备中',
      meta: 'IDENTITY · VISUAL SYSTEM',
      media: []
    }
  ]
}
```

真实媒体对象支持两种类型：

```js
{ type: 'image', src: '/works/brand/example.jpg', alt: '作品说明' }
{ type: 'video', src: '/works/brand/example.mp4', poster: '/works/brand/poster.jpg' }
```

## 媒体查看器

- 点击项目卡后打开覆盖全屏的深色媒体查看器。
- 当 `media` 为空时显示“作品媒体将在后续上传”，不显示破损资源。
- 图片使用完整包含模式，保留原始比例。
- 视频使用原生 `<video controls playsInline>`，不自动播放。
- 查看器提供关闭按钮，点击遮罩或按 Escape 均可关闭。
- 打开查看器时锁定页面滚动，关闭后恢复。
- 查看器标题关联当前项目，按钮包含可读的无障碍标签。

## 组件边界

- `workCategories.js`：保存分类、项目和媒体数据，后续内容只改数据文件。
- `CapabilityLink`：负责首页单行指针光晕和分类跳转。
- `WorkCategoryPage`：根据分类数据渲染二级页面。
- `MediaViewer`：负责图片、视频和无媒体状态。
- `App`：读取 URL、管理当前分类和浏览器历史同步。

## 响应式

- 1200px 版心延续到二级页面。
- 920px 以下项目卡两列，分类标题缩小。
- 620px 以下项目卡单列，头部按钮压缩，媒体查看器使用全宽内容区。
- 所有尺寸不得产生页面横向滚动。

## 实现范围

- 完成 01–04 指针高亮、可点击入口、四个二级页面、三张项目准备卡和媒体查看器框架。
- 不添加真实作品图片或视频，不新增外部依赖，不修改首页 Hero、About、优势模块或联系方式内容。

## 验收标准

- 01–04 鼠标光晕跟随位置变化，点击整行可进入正确分类。
- 四个查询参数分别展示对应分类标题和三张项目卡。
- 浏览器返回键、页面返回按钮和顶部导航均能正确回到主页面。
- 项目卡可打开和关闭媒体查看器，无媒体状态清晰可见。
- 图片和视频数据接口可直接替换为真实资源。
- 键盘、触屏与减少动态效果模式可正常使用。
- 1440px、920px 和 390px 宽度下无横向溢出。
- 生产构建成功，本地首页和四个二级页面可访问。
