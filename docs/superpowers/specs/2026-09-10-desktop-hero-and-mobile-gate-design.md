# PC 首屏与手机访问提示设计

## 目标

强化作品集在 PC 端的首屏识别，并停止维护手机端作品集布局。首屏英文主标题改为“PERSONAL PORTFOLIO”，五张扇形作品卡片适度放大；手机访问时不显示作品集主体，只显示使用电脑端访问的提示。

## PC 首屏

- 主标题使用单行 `PERSONAL PORTFOLIO`，语义明确指向个人作品集。
- `PERSONAL` 延续象牙白金属渐变，`PORTFOLIO` 使用现有香槟金强调。
- 保留现有从左向右的标题进场和卡片依次展开动画。
- 五张卡片在宽屏区间整体放大约 12%，中心卡片继续大于两侧卡片。
- 卡片组略微下移，使标题、说明文字和卡片之间形成清晰层级，不发生遮挡。
- 页面仅针对 PC 展示进行这次尺寸优化；现有桌面导航、背景、颜色和其他模块不变。

## 手机访问

- 在窄于 `768px` 的视口中隐藏网站主体和开场加载动画。
- 显示独立的全屏提示页，包含 `LT.` 标识、“DESKTOP EXPERIENCE”标签、中文提示“请使用电脑端访问”以及简短英文辅助文案。
- 提示页沿用深色、香槟金和细网格视觉语言，保持品牌一致性。
- 不提供“继续访问”按钮，避免进入未维护的手机布局。
- 提示使用纯 HTML/CSS，不新增图片、脚本或高耗能动画。

## 可访问性与性能

- 手机提示文案保持足够对比度，并使用语义化状态区域。
- PC 动画仍遵循现有的 `prefers-reduced-motion` 降级规则。
- 卡片放大仅调整布局尺寸，不增加图片分辨率、网络请求或运行时计算。

## 验证标准

- 1440px 与 1920px 宽度下，首屏标题完整，五张卡片均位于视口内且不遮挡标题。
- 中心卡片视觉权重明显高于左右卡片。
- 767px 及以下只显示电脑端访问提示，不显示导航、首屏或其他作品内容。
- 768px 及以上正常进入完整作品集。
- lint、生产构建和 GitHub Pages 路径检查通过。
