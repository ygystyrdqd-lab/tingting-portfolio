# 品牌视觉二级页面单项目设计

## 目标

将“品牌视觉设计”二级页面的项目卡片从三个缩减为一个，仅保留“品牌项目 01”。

## 变更范围

- 从 `brand` 分类的 `projects` 数据中删除“品牌项目 02”和“品牌项目 03”。
- 保留“品牌项目 01”的标题、元数据、点击行为和媒体数据结构。
- 项目数量变为一个后，复用现有 `layout-single` 通栏布局，不增加新的样式或组件逻辑。

## 不变范围

- 电商与活动视觉、包装与物料延展、三维视觉表现三个二级页面不变。
- 二级页面导航、打开时回到顶部、入场动画、悬停效果和媒体查看器不变。
- 品牌视觉页面的标题、说明文字和主题配色不变。

## 验收标准

1. 品牌视觉二级页面只显示“品牌项目 01”。
2. 唯一卡片以现有单卡片通栏样式显示。
3. 卡片可以正常点击并打开媒体查看器。
4. 其他三个分类的项目数量和布局不受影响。
5. 项目能够通过 lint 和生产构建检查。
