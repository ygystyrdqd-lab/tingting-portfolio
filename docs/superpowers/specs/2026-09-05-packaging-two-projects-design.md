# 包装与物料延展双项目设计

## 目标

将“包装与物料延展”二级页面的项目卡片从三个缩减为两个，仅保留“包装项目 01”和“包装项目 02”。

## 变更范围

- 从 `packaging.projects` 数据数组中删除 `packaging-03`。
- 保留 `packaging-01` 与 `packaging-02` 的标题、元数据、媒体结构和点击行为。
- 项目数量变为两个后，复用 `WorkCategoryPage` 现有的 `layout-pair` 布局。

## 布局与交互

- PC 端两张卡片并列显示。
- 宽度小于 `760px` 时两张卡片自动改为单列。
- 卡片悬停、点击打开媒体查看器、关闭弹窗、导航悬浮和返回作品行为保持不变。

## 不变范围

- 包装分类的页面标题、说明文字和主题色不变。
- 品牌视觉、电商与活动视觉、三维视觉表现、AIGC 视频广告四个分类不变。
- 不新增或删除图片资源，不修改组件和 CSS。

## 验收标准

1. 包装二级页面只显示“包装项目 01”和“包装项目 02”。
2. 页面使用现有 `layout-pair`，PC 双列、手机单列。
3. 两张卡片均可点击并正常显示媒体空状态。
4. 页面从顶部打开，导航和返回作品功能正常。
5. 其他四个分类不受影响。
6. lint 与生产构建通过，浏览器控制台无新增错误。
