# 石墨香槟金配色调整规格

## 目标

将视觉设计师作品集从高饱和霓虹色体系调整为更成熟、克制且具有编辑感的“石墨香槟金”体系。保持现有页面结构、排版、3D 轮播与滚动动效不变，仅统一颜色、光效和交互状态。

## 核心色板

- 页面主背景：`#0B0908`，温润石墨黑。
- 深层背景：`#070605`，用于 Hero 与项目区的暗部。
- 卡片表面：`#211B17`，形成克制的暖棕灰层次。
- 主文字：`#F0ECE5`，避免冷白造成过强反差。
- 辅助文字：`#9A8D80`，用于说明、编号和元信息。
- 暖纸背景：`#E9E3D9`，用于能力章节。
- 主强调色：`#D0AD7D`，用于品牌标记、关键词、按钮和动态光效。
- 强调色高亮：`#E3C59E`，仅用于悬停和局部高光。
- 深色文字：`#17110D`，用于暖纸色与香槟金表面。
- 边框：深色区使用 `rgba(240, 236, 229, 0.14)`，浅色区使用 `rgba(23, 17, 13, 0.18)`。

## 页面映射

### 全局与导航

- 浏览器背景、主页面背景和浮动导航统一为石墨黑。
- 导航滚动后的半透明背景采用暖黑，不出现偏蓝灰色。
- `LT` 标记、状态点和联系按钮使用香槟金；按钮文字使用深色文字。
- 主标题银灰渐变调整为暖银与浅香槟灰，不使用冷蓝银。

### Hero 与动态效果

- 透视方格由荧光绿改为低透明香槟金。
- 环境光晕使用暖棕金，避免大片橙色。
- 粒子和移动光轨由粉色改为香槟金，亮度低于文字高光。
- 3D 卡片由多色方案收敛为烟棕、暖石墨、低饱和酒红与灰金。
- 当前选中卡片保留更明亮的金色标记，其他卡片降低饱和度和对比度。

### 视觉跑马灯与 About

- 跑马灯卡片沿用 Hero 的暖中性色，不再为每张卡分配明显不同色相。
- About 背景使用主石墨黑，人物占位由冷灰改为暖灰。
- 环形装饰、经验数字和强调词使用香槟金。

### Capabilities

- 背景由冷白改为暖纸色。
- 正文、边框与图标使用深棕黑。
- 列表悬停背景使用浅香槟金，文字维持深色，保证对比度。

### Projects

- 项目区背景使用深层背景色。
- 三张项目卡分别使用烟棕、暖灰褐和低饱和酒红，全部带相同暖色底调。
- 卡内抽象几何体以暖象牙、香槟金和透明铜色为主。
- 项目按钮统一使用香槟金，不为不同项目分配独立按钮颜色。

### Contact

- 整屏背景使用主强调色 `#D0AD7D`。
- 标题、描边字、分隔线和链接使用深色文字。
- 悬停只做位移、旋转或透明度变化，不引入新的色相。

## 使用规则

- 页面只保留一类彩色强调：香槟金及其明暗变化。
- 大面积区域只能使用主背景、深层背景、暖纸背景或主强调色。
- 低饱和酒红仅限项目卡背景，不用于按钮、正文或导航。
- 粉色、荧光绿、亮蓝和高饱和紫色全部移除。
- 动态光效的视觉强度低于正文，不能影响标题可读性。
- 原有响应式布局与 `prefers-reduced-motion` 行为保持不变。

## 验收标准

- 全站不存在旧的粉色与荧光绿色值。
- Hero、跑马灯、About、能力、项目和联系区使用统一暖色底调。
- 深色区正文与背景保持清晰对比；暖纸色和香槟金表面使用深色文字。
- 卡片悬停、按钮和动态光效只使用色板内颜色。
- 页面结构、内容、滚动逻辑和 3D 轮播行为不发生变化。
- 本地预览可用，生产构建成功。

## 本次不包含

- 调整页面结构、字号或区块顺序。
- 添加正式作品图片或人物照片。
- 安装 React Bits Pro Hero 7。
- 新增页面、表单或数据功能。
