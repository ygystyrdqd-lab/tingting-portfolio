# 轻量网页视频预览版设计

## 目标

为作品集中的六支视频重新生成适合 GitHub Pages 的轻量网页预览版，显著缩短开始播放时间，同时保留原始高清视频文件，不改动作品内容和现有播放器界面。

## 已确认问题

- 线上视频文件均存在，支持 `206 Partial Content`，播放器兼容性修复也已发布。
- GitHub Pages 实测下载速度波动很大，部分视频约为 32–116KB/s。
- 当前发布副本单支约 6–31MB，在较慢网络下仍需等待几十秒到数分钟。
- 六支原始素材均保存在 `C:\Users\Mayn\Desktop\作品集`，时长为 15–61 秒，可从原片重新编码，避免对压缩副本再次转码。

## 采用方案

### 从原片生成网页预览副本

- 原始视频保持不变，仅替换 `portfolio-site/public/work` 中的网站发布副本。
- 输出统一为 MP4：H.264 视频、AAC 音频、`yuv420p` 像素格式。
- 保留原始画幅比例，输出为轻量 1080p，最长边限制为 1920px；帧率最高 30fps。
- 使用质量优先的可变码率编码，并设置约 2Mbps 的视频码率上限，避免动态画面产生过大的文件。
- 音频使用 AAC 80–96kbps。
- 使用 `faststart` 将 MP4 索引放在文件头，支持边下载边播放。

## 体积目标

- 15–29 秒的视频：单支约 4–8MB。
- 61 秒的免疫细胞科普片：目标约 14–17MB。
- 六支视频总量目标从当前约 91.5MB 降至 45MB 左右。
- 如果某支视频超过目标，优先小幅提高压缩率，同时保持 1080p 输出尺寸。

## 画质约束

- 人脸、产品文字、包装边缘和高光不能出现明显马赛克或严重色带。
- 保留原始音轨并确保音画同步。
- 抽查每支视频开头、中段和结尾；出现明显质量问题时回退该支视频并单独调整参数。
- 网站预览版用于在线展示，原片继续作为高清母版保存在作品集源文件夹。

## 验证

- 检查输出视频可解码、时长正常、H.264/AAC、最高 30fps、最长边不超过 1920px并包含 `faststart`。
- 比较压缩前后文件大小，总量达到目标。
- 在本地浏览器逐一确认六支视频能点击播放，且无黑帧、无音画不同步。
- 运行视频加载专项检查、桌面体验检查、代码检查和生产构建。
- 发布后确认 GitHub Pages 构建成功，所有线上视频返回 `206 video/mp4`。

## 不在本次范围

- 不更换 GitHub Pages 托管。
- 不接入第三方 CDN、HLS 或多清晰度切换。
- 不修改作品卡片、弹层和播放器视觉样式。
