# 二级作品页从上到下进场动效设计

## 目标

统一品牌视觉、电商与活动视觉、包装与物料延展、三维视觉表现四个二级页面的进入方向。页面内容按照视觉阅读顺序从上到下展开，保持现有暗色高级质感、较慢节奏和丝滑缓动。

## 动效顺序

1. 英文分类标签从上方轻微下落，并通过由上至下的遮罩显现。
2. 中文主标题从上方进入，横向压缩逐步恢复至正常比例；遮罩方向同步改为从上至下展开。
3. 项目简介与滚动提示由上方依次下落就位。
4. 项目卡片按照页面中的排列顺序分批触发；每批卡片从上方下落到原位，卡片内部图片继续保留轻微滚动视差。

## 视觉参数

- 分类标签初始垂直位移约 `-36px`。
- 主标题初始垂直位移约 `-120px`，横向比例约 `0.8`。
- 简介初始垂直位移约 `-35px`。
- 项目卡片初始垂直位移约 `-90px`。
- 所有动画继续使用 `power3.out` / `power4.out`，不使用弹跳回弹。
- 动画完成后清除临时行内变换，避免影响卡片悬停效果。

## 范围与兼容性

- 仅修改二级页面共用的 GSAP 动效 Hook，四个分类自动保持一致。
- 二级页面顶部返回按钮统一显示为“返回作品”，点击后直接进入首页的作品分类屏 `#capabilities`。
- 从二级页面返回作品分类时跳过首页 Opening，避免先显示首页首屏再跳转；普通刷新或进入首页仍保留 Opening。
- 不修改页面布局、项目数据或媒体弹层。
- `prefers-reduced-motion` 用户保持无位移动画的静态展示。
- 使用生产构建、代码检查和四个分类路由响应进行验证。

## 验收标准

- 四个二级页首屏内容明确呈现由上至下的阅读节奏。
- 项目卡片不再从下方向上浮入。
- 四个二级页顶部按钮均显示“返回作品”，并准确返回作品分类屏。
- 动画结束后悬停位移、图片扫光、点击项目均正常。
- 无新增构建或代码检查错误。
